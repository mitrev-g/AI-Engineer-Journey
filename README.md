# AI Engineering Journey

I'm working towards becoming an AI engineer by building projects, studying the theory behind them, and improving my software engineering skills along the way.

This repository tracks my progress, from Python and data structures to machine learning, deep learning, LLMs, and production AI systems.

I want to understand how things work, be able to implement them myself, and learn how to build systems that are reliable outside a notebook.

## Data structures and algorithms

I'll study DSA throughout the journey, with a focus on understanding the trade-offs behind different solutions.

Topics include:
- Arrays, strings, hash maps, and sets
- Linked lists, stacks, and queues
- Searching and sorting algorithms
- Recursion and divide and conquer
- Trees, heaps, and graphs
- BFS, DFS, and shortest paths
- Greedy algorithms, backtracking, and dynamic programming
- Big O time and space complexity

For each topic, I'll work through implementations and problems rather than relying only on explanations.

## How I approach projects

For each substantial project, I'll aim to document:

- The problem and the dataset
- The approach and reasoning behind it
- The baseline and models I tested
- Evaluation metrics and results
- Mistakes, limitations, and lessons learned
- Tests, setup instructions, and architecture where relevant

I'll prioritize understanding and reproducibility over chasing a high score or adding tools for the sake of it.
